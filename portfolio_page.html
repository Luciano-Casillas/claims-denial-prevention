🏥 Claims Denial Prevention Analytics

Healthcare claims analysis: 200K claims, $10.4M prior auth opportunity, XGBoost model with 1.18x top-decile lift

Python 3.12 Streamlit Plotly XGBoost SQL Healthcare

Project Summary

Analyzed 200,000 synthetic health insurance claims to identify denial patterns, quantify recovery opportunities, and build a predictive model for prioritized intervention. Built a 7-tab interactive Streamlit dashboard with root-cause analysis, provider performance breakdown, risk prediction, and financial scenario modeling.

KEY FINDING
Prior authorization delays drive $10.4M annually (35% of all denials). 54% appeal successfully, making this the highest-ROI recovery target. Network affiliation has zero correlation with denial rates, pointing to process quality as the bottleneck, not network tier.

Core Findings

  • Prior Auth Delays: $10.4M -- 35% of denied dollars; 54% appeal success rate. Addressable through process automation and SLA enforcement.
  • Billing Errors: 61% Appeal Success -- Highest recovery rate among all reasons. $3.64M in recoverable denials with dedicated appeals program.
  • Network Affiliation: Non-Factor -- In-network 3.95% vs out-of-network 3.87% denial rate. Process quality, not network tier, drives outcomes.
  • Denials Are Systemic -- Top provider $150K (0.5% of total). Only 2 members out of 100K with 3+ denials. Spread across network, not concentrated.
  • Coverage Limits: Unrecoverable -- $4.07M (14% of denials) are policy-defined maximums with no appeal pathway. Should communicate upfront to members.
  • Risk Model Concentrates High-Risk Claims -- XGBoost model with 1.18x lift in top decile. Features: claim amount (10.71%), plan type (9.46%), chronic condition (9.20%).
  • Year-1 Recovery Potential: $6-8M -- Conservative scenario: $3-5M from prior auth speedup alone (16.7x ROI on $300K investment).

Dashboard Features

  • Tab 1 -- Overview: KPIs, claim status composition, top denial reasons, executive summary metrics
  • Tab 2 -- Root Cause Analysis: Denied dollars and appeal success rates by denial reason; identifies recoverable vs. unrecoverable categories
  • Tab 3 -- Provider Performance: Provider-level denial rates, specialty variation, network correlation analysis; confirms no outliers or systemic provider issues
  • Tab 4 -- Risk Analysis: XGBoost model decile lift, feature importance, member concentration; shows top 2 deciles capture 31% of denials from 20% of volume
  • Tab 5 -- Financial Impact: Interactive scenario simulator for save rate, cost per contact, recovery potential; models 3 investment scenarios (conservative, moderate, aggressive)
  • Tab 6 -- Recommendations: Tiered action plan (Immediate, Short-Term, Strategic) grounded in data findings; includes timeline, investment levels, and expected ROI
  • Tab 7 -- Cross-Industry: Framework translation showing how healthcare denial patterns apply to pharmacy, auto insurance, and other domains

Technical Stack

  • Data Generation: Python 3.12 with NumPy (reproducible seed 42) for 200K synthetic claims
  • Data Analysis: Pandas for aggregation; SQL for discovery queries across 5 sections
  • Modeling: XGBoost with scale_pos_weight for imbalanced target (3.93% denial rate); feature importance via tree-based methods
  • Dashboard: Streamlit (7 interactive tabs) with Plotly charts and CSS styling
  • Color Palette: Production standard (Navy #0A3360, Blue #0077B3, Green #08CAA9, White background)
  • Deployment: Streamlit Community Cloud with GitHub integration
